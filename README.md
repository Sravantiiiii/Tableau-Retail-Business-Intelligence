# Retail Business Intelligence & Customer Analytics Platform

## Project Overview
Developed an end-to-end Retail Analytics project using Tableau to analyse sales performance, customer behaviour, product performance, employee performance and revenue projections.

## Datasets Used
- Customers
- Orders
- Products
- Order Items
- Employees

## Dashboards

## Key Learning Outcomes
- Data modelling and data analysis
- Interactive dashboard development
- Customer and product analysis

- Revenue trend analysis and business insights

## Conclusion
This Tableau Capstone Project provided practical experience in transforming raw retail data into meaningful business insights. By developing five interactive dashboards, I analysed sales performance, customer behaviour, product performance, employee performance and revenue growth scenarios.

I gained hands-on experience with data modelling, calculated fields, LOD expressions, table calculations, parameters, sets and dashboard development.

Overall, this project strengthened my Tableau and data analytics skills and helped me understand how data visualization supports better business decision-making.
